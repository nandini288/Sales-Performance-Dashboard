# Sales Performance Dashboard (Tableau)

## Overview

This project presents an interactive Tableau dashboard designed to analyze sales performance across different products and countries. The dashboard provides key insights into revenue, profit, tax metrics, and sales trends, helping businesses make data-driven decisions.

## Features

* KPI cards for Sales, Profit, and Tax metrics
* Product-wise sales performance analysis
* Country-wise profit comparison
* Sales trend visualization
* Geospatial sales mapping
* Interactive filters and drill-down capabilities

## Tools & Technologies

* Tableau
* Data Visualization
* Dashboard Design
* KPI Reporting
* Business Intelligence

## Dashboard Insights

* Identified top-performing products based on sales and profit.
* Compared profitability across different countries.
* Tracked sales trends to understand business performance.
* Visualized geographical sales distribution using maps.

## Project Objective

To transform raw sales data into meaningful visual insights that support strategic business decisions and performance monitoring.
